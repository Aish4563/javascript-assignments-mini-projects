# JavaScript Assignments & Inventory Mini Project

Six assignments plus a capstone **Product Inventory & Analytics Dashboard**.

## Run it in the browser
Open `index.html` (double-click it, or use GitHub Pages). Press **Run** on any card.
Untick "Ask me for input" to use default values instead of pop-ups.

## Run it in Node.js
```bash
node assignments/01-variables-datatypes.js
node mini-project/inventory.js
# or: npm run all
```
In Node, `prompt()` is not available, so default inputs are used (bill 100, tip 15, score 85, product Monitor at 150).

## Structure
```
index.html
assignments/   01 to 06
mini-project/  inventory.js
```
